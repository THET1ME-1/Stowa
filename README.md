# Stowa

Черновик, который разбирает себя сам. Закидываешь в строку ссылку, фото, голосовое, файл или «напомни завтра в 10», и приложение раскладывает вещь по папке, ставит теги, вытаскивает напоминание и связывает с похожими заметками. Та же строка ищет: пока печатаешь, над ней видно, что уже лежит.

- Сохранение мгновенное и без интернета, всё лежит на телефоне.
- Правила тегов раскладывают без сети, ИИ разбирает остальное по твоему собственному ключу (OpenRouter или любой поставщик с протоколом OpenAI).
- Доска картинок и холст как в PureRef, заметки в Markdown как в Notion, связи как в Obsidian.
- Закинуть можно из меню «Поделиться», через своего бота Telegram и с виджета.

Android, Flutter. Интерфейс на семи языках. В разработке.

## Где что

- `docs/specs/2026-11-02-stowa-design.md` — описание приложения
- `docs/plans/2026-11-02-stowa-plan.md` — план разработки по вехам
- `design/mockup/Stowa.html` — макет экранов (исходник `template.html`, сборка `python3 design/mockup/build.py`)

## Команды

- `flutter pub get`, затем `dart run build_runner build --delete-conflicting-outputs` (база) и `flutter gen-l10n` (словари)
- `flutter test`, `flutter analyze`
- Строки интерфейса: `python3 tool/add_strings.py строки.json`, русский и английский обязательны
- Шрифт иконок: `python3 tool/build_icon_font.py`; сборка идёт с `--no-tree-shake-icons`, иконки тегов выбираются по имени
