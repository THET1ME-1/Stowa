# Кладовка

Черновик, который разбирает себя сам. Закидываешь в строку ссылку, фото, голосовое, файл или «напомни завтра в 10», и приложение раскладывает вещь по папке, ставит теги, вытаскивает напоминание и связывает с похожими заметками.

- Сохранение мгновенное и без интернета, всё лежит на телефоне.
- Правила тегов раскладывают без сети, ИИ разбирает остальное по твоему собственному ключу (OpenRouter или любой поставщик с протоколом OpenAI).
- Доска картинок и холст как в PureRef, заметки в Markdown как в Notion, связи как в Obsidian.
- Закинуть можно из меню «Поделиться», через своего бота Telegram и с виджета.

Android, Flutter. В разработке.
