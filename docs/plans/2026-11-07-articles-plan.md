# Статьи — план

> **Сделано 7 ноября 2026, задачи 1–8.** Отступления: колонка цитаты `quote`, а не `text` (имя `text` перекрывает построитель drift). Поиск строки сверяет совпадения со списком `_factParts`, поэтому текст статьи и цитаты (`FactKind.highlight`, только для поиска) дописаны и туда — без этого индекс находил, а строка нет. Минуты чтения в карточке страницы берутся из текста статьи, чтобы совпадать с «Читать». Проверено на эмуляторе со снимками.

**Описание:** `docs/specs/2026-11-07-articles-design.md`. Читать вместе.

**Общие правила:** тесты сперва (красный → зелёный); тесты локально только затронутых файлов с потолком, весь набор — `check.yml` после пуша; строки — `tool/add_strings.py` на 7 языков; коммит и пуш после каждой задачи; в интерфейсе — «заметки».

## Задачи

1. **Разбор статьи** `domain/article_text.dart`: `ArticleBlock` (kind heading|paragraph|quote|item|code|image, text, level, src, ordered), `Article` (title, byline, site, published, blocks, words, minutes, plainText), `Article? extractArticle(String html, Uri page)`. Тесты: статья в `<article>` без меню и подвала; корень по очкам без `<article>`; блоки с unlikely-классами вырезаны; список, цитата, подзаголовок, картинка с абсолютным адресом и подписью; страница-товар с тремя строками — null; плотные ссылки (меню из абзацев) отброшены.
2. **Схема v10.** `items.gone_at`, `gone_kept`, `link_checked_at`, `read_position`; таблица `highlights`; триггеры очереди хранилища для `highlights` (`item:`). `FactKind.articleText` в поиске. Тесты: миграция v9→v10, правка `read_position` и `gone_at` не ставит заметку в очередь, цитата ставит.
3. **Цитаты в файле** `vault_note.dart` (`highlights`), писатель и читатель хранилища. `refreshFactsText` с цитатами. `HighlightsRepository` (add, setNote, remove, watch). Тесты: запись и чтение свойства, круг через хранилище, поиск находит пометку.
4. **Извлекатель `article`** и сброс его прогона вместе с `page` в `PageFetchExtractor`. Тесты: статья даёт `articleText` со словами и минутами, ролик и товар — нет.
5. **Читалка** `features/reader/reader_screen.dart`: шапка (назад, «Оригинал»), полоска прочитанного, блоки, место остановки, выделение с круглыми кнопками, подсветка, лист пометки, строка «Оригинал удалён». Кнопка «Читать · N мин» на странице заметки и список «Цитаты» там же. Виджет-тесты.
6. **Проверка ссылок** `services/link_checker.dart`, фон `stowa-links`, экран «Битые ссылки» в настройках, метка на карточках ленты и папки. Тесты: 404 → мёртвая, DNS без единого ответа → не решение, ожила → снята, 7 дней.
7. **Картинки статей:** включатель в настройках, извлекатель `article_images`, показ в читалке. Тесты извлекателя с поддельной сетью.
8. **Документы и проверка:** CLAUDE.md, шапка плана, проверка на эмуляторе со снимками.
