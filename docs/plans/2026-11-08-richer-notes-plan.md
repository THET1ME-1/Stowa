# Заметка богаче — план

**Описание:** `docs/specs/2026-11-08-richer-notes-design.md`. Читать вместе.

**Общие правила:** тесты сперва (красный → зелёный); локально только затронутые файлы с потолком, весь набор — `check.yml` после пуша; строки — `tool/add_strings.py` на 7 языков; коммит и пуш после каждой задачи; код только Read+Edit/Write.

**Где может укусить:** триггеры SQLite не умеют `WITH` — потомков папки перечислять вложенными подзапросами; переезд каталога папки с вложенными (писатель двигает файлы по одному, пустые каталоги чистит `_prune`); заметка Obsidian с картинкой в конце текста (раньше уходила в хвост); имя вложения меняется при переезде из входящих (`_gather` снимает номер `\d+_`); автосохранение раз в секунду и история.

## Задачи

1. **Дерево папок.** Схема v11: `folders.parent_id` (null — верхняя). `domain/folder_tree.dart`: `FolderTree.of(List<FolderRow>)` — `path(id) → List<String>`, `depth(id)`, `descendants(id) → Set<String>`, `children(id)`, `canNestInside(id)` (глубина < 3), `targetsFor(moving)` (без себя и потомков, глубина поддерева влезает), `pathLabel(id)` «Дом / Ремонт». `FolderCard`: `parentId`, `path`, `count` с вложенными, `ownCount`. `FoldersRepository`: `create(name, {parentId})`, `move(id, parentId)`, `delete` поднимает заметки и вложенные к родителю и отдаёт `FolderRemoval` для `restore`. Тесты: дерево, глубина, счёт с вложенными, удаление и возврат, перенос под потомка запрещён.
2. **Хранилище.** `notePath` по полному пути папки; писатель берёт путь у дерева; триггер `vault_folders_rename` — `UPDATE OF name, parent_id`, заметки папки и потомков до 8 уровней вложенными подзапросами (миграция пересоздаёт триггер). Читатель: `_folderFor` заводит цепочку по каталогам, ключ — путь в нижнем регистре; каталог вложений (рядом `X.md`) папкой не считается. Слежка `VaultWatch` — каталоги до любой глубины. Тесты: запись в подкаталог, переименование родителя переносит вложенные, перенос папки, чтение `A/B/C/n.md` даёт цепочку, повторное чтение не плодит папок.
3. **Экраны папок.** Экран папки: строка вложенных пилюлями (`FolderShelf` с `parentId`), путь родителей в шапке, меню «Новая папка внутри» (скрыто на глубине 3) и «Переложить в…» (лист выбора с «Наверх»). Главная — только верхние. Каталог — дерево с отступами. Выбор папки (переложить, `@`, «Поделиться», «Разобрать», правило тега) — путь под именем. ИИ — `FolderForAi.name` полным путём. Строки. Тесты: вложенная видна в родителе, не на главной; создание внутри; перенос; `@` находит вложенную по имени и показывает путь; 320 dp при шрифте 1.3.
4. **История.** Таблица `note_versions` (id, item_id, title, body, saved_at), схема v11. Триггер `items_history` на `UPDATE OF title, body`: старое состояние в снимок, если `julianday(new.updated_at) - julianday(old.updated_at) >= 10 мин`; там же чистка — старше 30 дней и не в 50 последних. В хранилище `.stowa/history/<id>.json` (цель очереди `history:<id>`, писатель и `rebuild`). `domain/text_diff.dart`: `diffLines(a, b) → List<DiffLine>` (same, added, removed) по LCS. `HistoryRepository`: `watch(itemId)`, `restore(versionId)`. Экран `features/item/history_screen.dart`, пункт «История» в «⋮». Тесты: снимок после перерыва, нет снимка внутри сессии, чистка, разница строк, возврат создаёт снимок, файл истории пишется и читается при пересборке.
5. **Картинки в тексте.** `NoteBlock` `ImageBlock(name)` для строки `![[имя]]`; `resolveEmbed(name, attachments)`. Страница заметки рисует картинку в тексте, галерея — без вложенных в текст. В правке «фото» вставляет строку на место курсора, файл получает имя `Фото ГГГГ-ММ-ДД ччммсс.jpg`; `_gather` при смене имени правит текст. Файл: хвост — только строки с путём, хвост пишется только для невложенных в текст. Лента, `linesUnderTitle`, подписи — без строк `![[…]]`. Тесты: разбор блоков, хвост и текст в файле туда-обратно (картинка в конце текста остаётся в тексте), галерея без вложенных, вставка на место курсора, лента без `![[`.
6. **Проверка и документы.** Эмулятор со снимками: вложенные папки на главной, в папке, в каталоге, в файлах хранилища; история с разницей и возвратом; картинка между абзацами. CLAUDE.md, шапка плана.
