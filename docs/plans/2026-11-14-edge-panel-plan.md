# «Под рукой»: план работ

> **Для исполнителя:** идти по задачам по порядку, отмечая `- [ ]`. Каждая задача кончается проверкой и коммитом.

**Цель:** корешки закреплённых заметок у края экрана поверх любого приложения; касание или свайп — полка Stowa со строкой один в один; любую заметку — плавающим стикером, который сворачивается в круг на своём месте.

**Устройство:** Kotlin-служба `EdgeService` держит окна поверх (`TYPE_APPLICATION_OVERLAY`): корешки — нативный `View`, полка — `FlutterView` с движком `edgeMain`, стикер — `FlutterView` с движком из `FlutterEngineGroup` (`stickerMain`). Dart и Kotlin говорят по каналу `stowa/edge`. Вся раскладка (где корешки, куда раскрыть стикер) — чистые функции Dart с тестами; Kotlin только ставит окна туда, куда скажут.

**Стек:** Flutter 3.47, Riverpod, Drift (схема 18, база не меняется), Kotlin, `WindowManager`, `FlutterEngineGroup`.

**Описание:** `docs/specs/2026-11-14-edge-panel-design.md` (что строим и почему; разделы 2а — решения хозяина, 6 — риски). Макет: https://claude.ai/artifact/4MK46kLpUwxhPHGxJEA4nY

## Общие правила

- Только Android. На iPhone канал `stowa/edge` — пустышка, раздела настроек нет (`Platform.isAndroid`).
- Строка в полке — сам `LineDock`, не копия. Ни одной функции меньше и ни одной больше, чем в приложении.
- Никакой привязки к приложениям и права `PACKAGE_USAGE_STATS`.
- Без теней. Цвета — `Tokens`, `FolderPalette`; шрифты Unbounded + Onest; иконки `symbolIcon`.
- Строки — на 7 языках через `tool/add_strings.py`, «заметки», не «вещи»; подсказка — одно предложение.
- Правка кода — Read + Edit, новые файлы — Write, без скриптов.
- Тесты локально — только затронутые файлы: `TMPDIR=~/.cache/flutter-tmp systemd-run --user --scope -q -p CPUQuota=500% -p MemoryMax=5G -p MemorySwapMax=0 nice -n 19 flutter test -j 3 <файлы>`; весь набор — `check.yml` после пуша.
- `check.yml` Kotlin не собирает: каждая задача с Kotlin проверяется profile-сборкой на эмуляторе (`crashtest`, `hw.ramSize=3072`, клетка 5,2 ГБ — CLAUDE.md, «Эмулятор»).
- Сборка на телефон — только по слову хозяина, пре-релизом на GitHub.
- Коммит после каждой задачи, по-русски, с двумя строками соавторства; пуш в `main`.
- **Всё движется плавно**, по таблице раздела 3а описания: кривые и длительности только из `Motion`, в Kotlin те же через `PathInterpolator`. Ни одного появления или исчезновения скачком. «Убрать анимацию» в системе — мгновенно. Каждая задача с движением кончается замером кадров (`addTimingsCallback` в журнал) на эмуляторе; на телефоне — после этапов 2 и 3.

## На что смотреть особо

Ни одна задача ниже сама это не ловит, поэтому тест на каждое — в задаче, которая владеет кодом.

1. **Поворот экрана и смена размера** (складной телефон, разделённый экран): корешки остаются у своего края на той же доле высоты, стикеры зажимаются в новый экран — задача 12, тест `sticker_geometry_test` «экран стал меньше».
2. **Замок.** Стоит «Код на вход» — полка не показывает ни одной заметки, корешки одного белого цвета (цвета папок выдают, что закреплено), стикеры при закрытии замка снимаются — задачи 5 и 9.
3. **Смена хранилища, пока полка открыта** — полка пересобирается на новую базу, стикеры чужого хранилища снимаются — задача 9, задача 13.
4. **Заметку удалили или скрыли, пока висит её стикер** — стикер исчезает, в списке стикеров её больше нет — задача 13.
5. **Процесс убит** — после подъёма службы корешки и стикеры на тех же местах и в том же виде (свёрнут/раскрыт) — задача 13, проверка на эмуляторе `kill -9`.
