# Stowa: конкуренты и деньги

Разбор 3 ноября 2026. Цены взяты с агрегаторов и страниц цен, местами они расходятся. Перед решением их надо сверить на сайтах самих сервисов.

## Есть ли такое же приложение

Целиком такого нет. В Stowa сошлись пять вещей, и у каждого конкурента есть одна-две из них:

1. Одна строка и записывает, и ищет, сохранение за 100 мс.
2. Разбор по папкам и тегам: правилами без сети, а ИИ по своему ключу.
3. Свой бот Telegram и «Поделиться» из любого приложения.
4. Папка как доска PureRef, холст и граф.
5. Место и карта заметок.

## Кто ближе всего

| Сервис | Что совпадает | Чем отличается | Деньги |
|---|---|---|---|
| **mymind** | «Сохрани что угодно», ИИ сам ставит метки, приватность, визуальная лента | Папок нет вовсе, только поиск. ИИ встроен. Приложение платное с первого дня, на Android слабое | Подписка, от ~$6/мес |
| **Mem** | Заметки разбирают себя сами, связи, агент | Только текст. Дорого: от $9 до $199/мес, лимиты на ИИ | Free, Plus $9, Pro $29 |
| **Saner.ai** | Входящие, ИИ ставит теги и находит похожее, упор на СДВГ | Работа и задачи, письма. ИИ на лимитах | Free (100 заметок), ~$8–12/мес |
| **Fabric** | «Не раскладывай, просто сохраняй», файлы и заметки в одном месте | Скорее облачный диск с ИИ, а не быстрая запись | Free, Pro ~$12/мес |
| **Notion (AI Sorter Inbox)** | Мобильные заметки сами разлетаются по базам | Тяжёлый Notion, нужен аккаунт и сеть | В подписке Notion AI |
| **Karakeep (бывший Hoarder)** | ИИ-теги по своему ключу OpenAI или своей Ollama — ровно наш подход | Только ссылки и закладки, ставится на свой сервер, для гиков | Бесплатно, открытый код |
| **Cosmos** | Визуальные закладки, ИИ-подписи, поиск по цвету | Pinterest для дизайнеров, соцсеть. На Android только веб-приложение | Free + подписка |
| **Milanote / Kosmik** | Доски с картинками и заметками | Всё раскладываешь руками | Milanote $10–12.5/мес, Kosmik $12–15/мес |
| **PureRef / Eagle** | Доска референсов | Только компьютер, вручную | Разовая покупка |
| **Excalidraw+** | Холст в браузере | Рисование, не хранилище | $6–7/мес за человека |
| **Самодельные боты Telegram** (zeroInbox, связки на n8n, Obsidian Telegram AI) | Переслал боту — ИИ разложил | Всё через свой сервер и настройку, готового приложения нет | — |

### Что из этого следует

- **Главный прямой соперник — mymind.** Та же мысль «сохраняй, мы разберём», та же приватность. Наши отличия: папки и правила, которые человек видит и правит; работа без сети; Android первым; бесплатный вход; свой бот.
- **ИИ по своему ключу у потребителя не встречается.** Он есть только у Karakeep, который ставят себе на сервер технари. Это плюс для гиков и минус для массы: обычный человек не пойдёт за ключом на OpenRouter.
- **Свой бот Telegram в готовом приложении не нашёлся ни у кого.** Есть только самоделки. Для русскоязычной аудитории, где Telegram — главный мессенджер, это сильная сторона.
- **Доска как PureRef внутри быстрых заметок** у конкурентов разнесена по разным продуктам: доски отдельно (Milanote, Kosmik), заметки отдельно (mymind, Mem).

## Деньги: что предлагаю

### Подписка — да, синхронизация в ней — да

Ориентиры по ценам: Obsidian Sync $4–5, Excalidraw+ $6–7, Raindrop Pro ~$3, mymind ~$6+, Milanote ~$10. Для русскоязычной аудитории разумно 199–299 ₽ в месяц, год со скидкой около 40%.

**Бесплатно навсегда** (это и есть вход):
- всё на одном телефоне;
- строка, правила, угадывание без сети, ИИ по своему ключу;
- свой бот, «Поделиться», виджет, карта, холст, граф;
- резервная копия файлом.

**Stowa+ за подписку:**
- синхронизация телефон ↔ телефон ↔ веб, со сквозным шифрованием — козырь против mymind и Mem;
- веб-версия: холст как Excalidraw и доска как PureRef на большом экране, перетаскивание картинок с компьютера;
- место под файлы в облаке (фото, видео, PDF) и история версий;
- публичная ссылка на доску или папку, как у Excalidraw.

Синхронизация — честный повод для платы: она стоит денег на сервер и хранилище, человек понимает, за что платит. Так её продаёт Obsidian.

### Реклама — скорее нет

- В хранилище личных мыслей реклама подрывает доверие. Главная фраза mymind — «без рекламы и слежки», ей придётся отвечать тем же.
- Баннер в строке ввода ломает главное обещание «сохранить за секунду».
- Ни у одного прямого конкурента рекламы нет.
- Если без неё никак: только в бесплатной веб-доске, которую человек открыл по чужой ссылке. Ещё вариант — ролик за награду (например, неделя синхронизации). В телефонной строке и в заметках рекламы не должно быть никогда.

### Развилка, которую надо решить до цен

Сейчас ИИ работает только по ключу человека, своего сервера и общего ключа нет. У всех конкурентов с подпиской ИИ встроен, и именно он — главная причина платить. Если подписка ИИ не включает, её держат только синхронизация и веб. Это работает (так живёт Obsidian), но аудитория уже: люди, которым важно, где хранятся их данные.

## Отзывы: на что жалуются

Отзывов мало и они разрозненные: App Store, Product Hunt, Capterra, блоги, Reddit. Часть обзоров партнёрская. Ниже то, что повторяется у разных людей.

| Сервис | Жалобы |
|---|---|
| mymind | Поиск промахивается мимо очевидного, нет подсказок при вводе. ИИ не размечает видео. Длинные посты X обрезаются. Расширение для браузера отваливается через несколько часов. Нет папок — кому-то это свобода, кому-то потеря контроля |
| Mem | Нет приложения для Android. Без сети почти не работает. Теги и поиск ненадёжны. Поддержка молчит. Цены менялись несколько раз за год. Бесплатно 25 заметок. При выгрузке теряются связи. «ИИ вместо структуры» восхищает в первую неделю и бесит к третьей |
| Saner.ai | Лимиты ИИ кончаются, пока разбираешься. После оплаты непонятно, за что платил. Подозрения на накрутку отзывов |
| Raindrop | Расширение выкидывает из аккаунта. Закладки не хранятся на устройстве, без сети их нет. Слабые импорт и восстановление. Просят ИИ-теги |
| Milanote | Нет работы без сети. Телефонное приложение — урезанный спутник компьютера. Нет истории правок. Бесплатно только 100 карточек |
| PureRef, Eagle | Нет облака и синхронизации, нет телефона. Тормозят на больших подборках |
| Google Keep | 13 лет не было поиска внутри заметки. Нет вложенных папок, форматирования, ссылок между заметками, картинок между абзацами. Не видно даты заметки |
| Cosmos | Вылетает, не пускает в аккаунт, поддержка не отвечает |
| «Избранное» Telegram | Поиск не прыгает к найденному. Ролики находятся только по подписи |

### Общие уроки

1. **Поиск — главная боль у всех**, даже у mymind, который продаёт именно его.
2. **Работа без сети** — чего не хватает почти всем облачным.
3. **Телефон — второй сорт** у Milanote, Mem и mymind на Android.
4. **Лимиты и скачущие цены** злят сильнее, чем просто высокая цена.
5. **Запертость:** выгрузка теряет связи и разметку.
6. **Падения и молчащая поддержка** убивают даже любимое приложение.

## Чего у нас нет, а у них есть

| Чего нет | У кого есть | Нужно ли нам |
|---|---|---|
| Расширение для браузера | mymind, Raindrop, Fabric, Karakeep | Да, вместе с вебом. Иначе с компьютера не сохранить |
| Копия страницы навсегда (ссылка умерла — текст остался) | Raindrop Pro, Karakeep | Да: читалка без сети и защита от удалённых страниц |
| Режим чтения статьи без рекламы | Raindrop, Karakeep, Readwise | Да, вместе с копией страницы |
| Выделения и пометки в статьях | Raindrop, Karakeep, Readwise | Да, после читалки |
| Поиск битых ссылок | Raindrop | Да, дёшево |
| Сохранение письмом (переслал на адрес — легло) | Raindrop, Mem | Позже: нужен свой почтовый адрес, то есть сервер |
| Общие папки и доски по ссылке | Milanote, Raindrop, Cosmos | Да, в подписке вместе с синхронизацией |
| Работа вдвоём на доске | Milanote, Kosmik | Позже |
| Вложенные папки | Raindrop, Milanote | Да: просят даже в Keep |
| История правок заметки | Notion, Obsidian | Да: просят в Milanote |
| Таблицы и картинки между абзацами | Notion, Milanote | Картинки — да, таблицы — позже |
| Шаблоны | Milanote, Notion | Позже |
| Похожие картинки, поиск по цвету | mymind, Cosmos, Eagle | Цвет — в плане, похожие — отпечаток картинки |
| Импорт из закладок, RSS | Raindrop, Karakeep | Закладки — в плане, RSS — позже |
| Приложение для компьютера | Все, кроме Keep на Linux | Веб закрывает |
