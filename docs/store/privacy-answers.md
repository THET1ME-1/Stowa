## Google Play: «Безопасность данных»

- Собирает или передаёт данные: **да**.
- Все данные шифруются при передаче: **да**.
- Способ запросить удаление: **нет** — данных, привязанных к человеку, у нас нет.
- Типы данных — один:
  - **Сведения о приложении и производительности → Журналы сбоев.** Собирается, не передаётся, необязательное (выключатель), цель — аналитика.
- Не объявлять: местоположение, фото, аудио, файлы, сообщения, контакты. Всё это обрабатывается на телефоне. В сеть уходит только по действию человека к выбранному им сервису (свой ключ ИИ, свой бот, карта по запросу) — это не наша обработка. **Сверить:** если проверка Google сочтёт поиск адреса передачей «примерного местоположения», объявить его как собираемое, необязательное, для работы приложения.

### Разрешения, которые Play проверяет отдельно (сверить)

- **`ACCESS_BACKGROUND_LOCATION`** — анкета в Play Console и видео: напоминание у места при закрытом приложении. Перед системным запросом приложение обязано само объяснить, зачем место в фоне (плашка `askPlaceReminder`, карточка `PlaceAlwaysCard`): проверить, что в тексте есть «местоположение», «в фоне или когда приложение закрыто» и зачем.
- **`MANAGE_EXTERNAL_STORAGE`** — анкета «Доступ ко всем файлам». Google пускает файловые менеджеры, резервное копирование и работу с документами. Довод: заметки — файлы Markdown в общей папке, которую открывает Obsidian. Риск отказа есть; запасной путь — сборка для Play без хранилища в общей памяти.
- **`USE_EXACT_ALARM`** — Play оставляет его будильникам и календарям. Для заметок с напоминаниями могут потребовать `SCHEDULE_EXACT_ALARM` с разрешением от человека. На нём держится и сторож корешков `EdgeWatchdog`.
- **`FOREGROUND_SERVICE_MICROPHONE`** — анкета типов служб переднего плана и видео: запись голосового с корешков поверх других приложений.
- **`READ_MEDIA_IMAGES`, `READ_MEDIA_VIDEO`** — анкета доступа к фото и видео. Довод: лоток галереи над строкой — основной способ закинуть фото.

## App Store: «Конфиденциальность приложения»

- Данные для отслеживания: **нет**.
- Данные, связанные с пользователем: **нет**.
- Данные, не связанные с пользователем: **Диагностика → Данные о сбоях**, цель — функциональность приложения.
- В `PrivacyInfo.xcprivacy` (шаг 8 плана iPhone): тот же тип `NSPrivacyCollectedDataTypeCrashData`, не связан, без отслеживания; причины API — `UserDefaults` (`CA92.1`), время файлов (`C617.1`), свободное место (`E174.1`), если плагины их зовут. **Сверить** по списку плагинов при сборке.
- Шифрование для экспорта (**сверить**): скрытые папки шифруются стандартным AES-GCM ради защиты данных человека. Обычно это попадает под исключение, и в `Info.plist` ставят `ITSAppUsesNonExemptEncryption = NO`.
