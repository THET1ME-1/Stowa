# Stowa без ИИ: сохранил — нашёл, вернулось само

3 ноября 2026. План к обсуждению, кода ещё нет.

## Зачем

Сохранять умеют все конкуренты. Проваливаются они в другом: через месяц человек не находит тот рилс, тот скрин, ту ссылку. Обещание Stowa — «сохранил что угодно, через месяц нашёл за три секунды, а нужное в нужный момент всплыло само».

ИИ по ключу остаётся надстройкой. Всё в этом плане работает:
- без ИИ и без движков распознавания;
- без сети, кроме одного раза при сохранении ссылки;
- на семи языках: ru, uk, en, de, es, ro, pl;
- в размере APK до 40 МБ (сейчас 29 МБ на arm64).

## Чего не делаем

- Распознавание речи и текста на телефоне (Whisper, Tesseract, ML Kit) — отложено.
- Свой сервер для ИИ.
- Скачивание роликов Instagram: Instagram его режет.

## Как устроено: одна труба для любой вещи

Каждая вещь после сохранения проходит цепочку **извлекателей**. Это маленькие правила без ИИ, и каждое достаёт из вещи **факты**: текст для поиска, дату, место, цену, длину, ингредиенты, предложенные теги, повод напомнить.

- **Факты лежат в одной таблице** `Facts(itemId, kind, key, value, at)`, их текст попадает в поиск. Новый вид знания — новый извлекатель, базу перестраивать не нужно.
- **У извлекателя есть номер версии.** Улучшили извлекатель — старые вещи прогоняются заново в фоне.
- **Две очереди.** Сетевые извлекатели (страница, субтитры) идут через очередь, как превью сейчас. Местные (EXIF, текст из DOCX) работают сразу после копирования файла.
- **Строка не ждёт ничего:** сохранение по-прежнему укладывается в 100 мс.

## 1. Поиск, который понимает человека

Поиск — фундамент: без него всё остальное бесполезно.

- **Формы слов на семи языках.** «Креветками» находит «креветки», «Straße» — «Straßen», «tomates» — «tomate». Для каждого языка — свой список окончаний, язык слова определяется по буквам (і, ї, є — украинский; ą, ł, ż — польский; ă, ș, ț — румынский; ä, ß — немецкий; ñ — испанский).
- **Буквы всех семи языков.** Сейчас слово режется на ü, і, ą, ș, и поиск по-немецки и по-польски ломается.
- **Транслит в обе стороны:** «kofe» находит «кофе», «кофе» находит «kofe».
- **Не та раскладка:** «rjatq» находит «кофе», «ащещ» — «фото».
- **Фразы о времени:** «вчера», «на прошлой неделе», «в мае», «прошлым летом», «год назад» — на семи языках. Используется уже готовый разбор дат.
- **Фразы о месте:** «в Кишинёве», «дома», «на работе», «рядом» — по названию места и отметкам «дом» и «работа».
- **Вид вещи:** «видео», «скрин», «голосовое», «pdf», «рецепт», «ютуб», «тикток».
- **Цвет:** «синее», «красная обложка» — по главным цветам картинки, без ИИ (см. раздел 4).
- **Длина:** «короткие ролики», «до 5 минут».
- **Под каждым ответом видно, где нашлось,** с подсветкой: «в субтитрах 0:42», «в PDF, стр. 3», «в ингредиентах».

## 2. Ссылки: страница сама говорит, что это

Почти каждый крупный сайт прячет в странице разметку schema.org (JSON-LD). Это готовые поля, без догадок:

| Что на странице | Что достаём | Что получает человек |
|---|---|---|
| Рецепт | ингредиенты, время готовки, порции | карточка рецепта, ингредиенты чек-листом «в магазин», поиск по ингредиенту |
| Товар | цена, валюта, магазин, наличие | цена на карточке, «товары до 500 лей» |
| Событие | дата, время, место | напоминание ставится само, место встаёт на карту |
| Место, заведение | адрес, координаты, часы работы | точка на карте, напоминание по месту одним касанием |
| Статья | автор, дата, время чтения | «почитать на 7 минут» |
| Фильм, книга | год, режиссёр или автор, рейтинг | поиск «фильм 2019» |
| Видео | длина, главы | очередь «посмотреть потом» со временем |

**Субтитры роликов.**
- YouTube и Shorts: дорожки субтитров, включая автоматические, тянутся без ключа (проверено). Фразы хранятся со временем: поиск находит фразу, касание открывает ролик с этой секунды.
- Главы YouTube: строки «0:00 Вступление» из описания становятся оглавлением.
- TikTok: субтитры из данных страницы (поле `subtitleInfos`), подпись автора и хэштеги.
- Instagram: подпись и хэштеги.
- **Хэштеги автора становятся предложенными тегами.** Подтверждаются касанием или правилом.

Сеть нужна один раз, при сохранении. Дальше всё на телефоне.

## 3. Перенести то, что уже накоплено

У человека тысячи вещей лежат в чужих местах. Перенести их — первый повод открыть Stowa.

- **«Избранное» Telegram:** экспорт из Telegram Desktop (`result.json` и папка с файлами). Каждое сообщение становится вещью, альбом — одной вещью, ссылки проходят извлекатели. Дата берётся из сообщения, а не дата переноса.
- Google Keep (Takeout), закладки браузера (HTML), папка Markdown (Obsidian), выгрузка mymind (CSV).
- **Дубли видны сразу.** Тот же адрес или та же картинка: «уже лежит в „Рецептах“ с 12 мая».

## 4. Фото, скриншоты, файлы — без распознавания

- **EXIF:** дата съёмки и место съёмки. Фото из поездки встаёт на карту там, где снято, а не где сохранено.
- **Скриншот или фото** различаются по размеру экрана, имени файла и отсутствию камеры в EXIF. Скриншоты — свой вид, свой фильтр.
- **Главные цвета.** Гистограмма картинки, считанная при сохранении, — 3–5 цветов. Работают поиск по цвету и сортировка доски по цвету, как в PureRef.
- **Дубли фото** ловятся отпечатком из 64 бит: уменьшить, сравнить яркость соседей. Это арифметика, не нейросеть.
- **Текст файлов:** DOCX, XLSX, PPTX, EPUB, ODT — это zip с XML, читается библиотекой, которая уже стоит. TXT, MD, CSV, JSON, HTML — как есть. Всё ищется, с указанием страницы или листа.
- **PDF:** системный `PdfRenderer` Android только рисует страницы, текст из него не достать. Нужен свой разборщик текстового слоя на Dart: без движка, но сложнее остальных, поэтому он последний. Сканы без текстового слоя без распознавания не прочитать.
- **Видеофайл:** длина, кадр-обложка, кадры на шкале через системный `MediaMetadataRetriever`.
- **QR-код на фото** (Wi-Fi, ссылка, билет) — разбор по алгоритму ZXing, без нейросети, около 1 МБ. Подключать или нет, решаем отдельно.

## 5. Текст заметки: умные места в строке

Разбор без ИИ, на семи языках, по шаблонам:
- **Телефон** — позвонить, **почта** — написать, **адрес** — открыть на карте.
- **Деньги:** «500 лей», «€20», «2 000 ₽». Сумма по папке: «потратил на ремонт».
- **Трек-номер посылки** — ссылка на отслеживание.
- **Промокод, пароль Wi-Fi, номер карты лояльности** — копируются одним касанием. Для паролей — спрятанное поле.
- **Даты и время** — уже есть. Добавить «на выходных», «вечером», «после работы» (время из настроек).
- **Чек-лист «купить …»** превращается в список покупок.

## 6. Вернуть в нужный момент — главное отличие

Здесь Stowa делает то, чего не делает никто.

- **Напоминание по месту.** «Купить кофе тут», «напомни, когда буду здесь», выбор точки на карте или адрес из события. Срабатывает в радиусе 100–300 м через системный `LocationManager`, без Google. Нужно разрешение на место в фоне.
- **Дом и работа без GPS.** По сети Wi-Fi: «напомни дома», «когда приду на работу». Срабатывает при подключении к своей сети. Дёшево по батарее, место наружу не уходит.
- **Очередь «Посмотреть потом».** Ролики и статьи с длиной: «у тебя 3 ролика на 12 минут». Вечером в выбранное время — одно тихое уведомление, если очередь не пуста.
- **«В этот день».** Ровно год, месяц, неделю назад ты сохранил это. Раз в день, только если есть что показать.
- **Недельная сводка.** Что сохранено и не открыто ни разу; что лежит «Без папки».
- **Список покупок у магазина.** Вещи с тегом #купить всплывают у отмеченных магазинов: их место берётся из событий и мест на карте.
- **Бюджет уведомлений.** Не больше одного возвращающего уведомления в день, тихие часы, отключение по видам. Иначе люди выключают уведомления совсем.

## 7. Порядок без ИИ

- **Умные папки:** сохраняемые запросы из поиска («ролики YouTube до 5 минут», «скрины за неделю», «всё, что сохранено в Кишинёве»). Видны рядом с обычными папками.
- **Папки по сайту и виду** предлагаются, когда вещей набралось много: «12 ссылок с habr.com — сделать папку?».
- **Правила видят факты:** «если рецепт → в „Рецепты“», «если цена > 1000 → тег #дорого», «если событие → напомнить за день».

## 8. Приватность, без которой не пойдут в люди

- Замок на приложение: PIN и отпечаток.
- Скрытая папка, которая не показывается в поиске без разблокировки.
- Резервная копия с паролем.
- Выгрузка всего в Markdown и папки: человек не заперт.

## Размер приложения

Бюджет — 40 МБ на arm64. Сейчас 29 МБ.

- Всё выше — правила и разборщики на Dart и системные API Android, примерно 1–2 МБ кода на всё.
- **Резерв.** Сейчас в приложении два полных шрифта Material Symbols. Если оставить только значки, которые предлагаются человеку, плюс значки интерфейса, это даст несколько мегабайт обратно. Замерить до начала работ.
- ZXing — около 1 МБ, если решим подключать.

## Очерёдность

| Шаг | Что | Почему сейчас |
|---|---|---|
| 1 | Поиск: формы слов на 7 языках, буквы, транслит, раскладка, фразы времени, вида и места | Всё остальное ищется через него |
| 2 | Труба извлекателей и таблица фактов | Каркас для шагов 3–6 |
| 3 | Ссылки: JSON-LD (рецепт, товар, событие, место, статья) и субтитры YouTube и TikTok с переходом к секунде | Самая заметная разница с конкурентами |
| 4 | Перенос «Избранного» Telegram и дубли | Первый повод поставить приложение |
| 5 | Возврат: место, Wi-Fi «дом и работа», «посмотреть потом», «в этот день», бюджет уведомлений | Главное отличие |
| 6 | Фото и файлы: EXIF, скриншоты, цвета, дубли, текст DOCX/XLSX/EPUB, потом PDF | Ищется то, что раньше было немым |
| 7 | Умные места в тексте и умные папки, правила по фактам | Порядок без ручной работы |
| 8 | Приватность: замок, скрытая папка, выгрузка | Перед выходом в люди |

Каждый шаг — рабочая сборка с тестами и проверкой на эмуляторе.

## Что решает строитель сам

- Списки окончаний и словари фраз для семи языков — по открытым источникам (Snowball, лёгкие стеммеры Савуа), с тестами на каждом языке.
- Радиус места по умолчанию — 150 м.
- Время вечернего уведомления «посмотреть потом» — 20:00, меняется в настройках.

## Что решает хозяин

- Подключать ли ZXing для QR (около 1 МБ).
- Разрешение на место в фоне: Google Play требует объяснения и видео, RuStore — нет.
- Импорт из других приложений: какие из списка нужны первыми.
