# Связи между заметками руками: `[[…]]` с подсказкой и «+ Связь»

13.11.2026. Хозяин: «`[[Название]]` не работает», «мне достаточно написать `[[`, вторая половина
заполнится сама, и появится список заметок для поиска — откуда я знаю название», «рядом с «+ Тег»
можно «+ Связь»».

## Почему не работало

1. Связь из `[[…]]` записывал только читатель хранилища — для файлов, исправленных снаружи
   (Obsidian). Набранное в самом Stowa связью не становилось.
2. Блок «Связано» показывал только похожие по словам; ручные связи и связи от ИИ из таблицы
   `links` в нём не появлялись никогда (только в графе).
3. `[[Заметка]]` в тексте — просто текст: не выделен и не открывает заметку.

## Как устроено

### Связи — откуда берутся

- **Из текста.** `[[Заголовок]]` и `[[Заголовок|подпись]]` в тексте заметки связывают её с заметкой
  этого заголовка (без учёта регистра). Не хранятся отдельно, а считаются из текста каждый раз:
  убрал `[[…]]` — связи нет, переименовал заметку — связь идёт за новым заголовком только через
  текст. Вставка картинки `![[…]]` связью не считается. Обратная связь видна у второй заметки:
  «Ссылается сюда».
- **Кнопкой «+ Связь»** на странице заметки рядом с «+ Тег»: лист с поиском по словам из заголовка
  и текста, касание связывает. Хранится в `links` с `source = manual` (уже пишется в
  `.stowa/links.json`, переживает переустановку).
- **ИИ** по ключу — как раньше (`source = ai`, с причиной).
- **Похожие** по редким словам и сайту — как раньше, до трёх.
- Читатель хранилища больше не пишет связи из `[[…]]` в `links`: они и так считаются из текста.

### «Связано» на странице заметки

Все связи одним блоком (вид прежний: строки-блоки с картинкой или значком вида): сперва из текста
и обратные, потом ручные, от ИИ, похожие. Под заголовком — почему:
«В тексте» · «Ссылается сюда» · «Связь вручную» · «ИИ: причина» · «Общее: пиво, хмель» ·
«Тот же сайт: habr.com». Крестик: у ручной — убрать связь (с «Отменить»), у ИИ и похожих —
«не связаны», больше не предлагать (как сейчас). У связи из текста крестика нет: её держит текст.

Граф папки рисует и связи из текста.

### `[[…]]` в тексте заметки

Показывается подписью (или заголовком) цветом ссылки с подчёркиванием, без скобок. Касание
открывает ту заметку; такой нет — плашка «Заметки «…» нет».

### Набор `[[` — подсказка

В строке ввода (и на весь экран) и в правке заметки:

- Набрал второй `[` подряд — сразу дописывается `]]`, курсор встаёт между скобками.
- Пока курсор внутри `[[…]]`, над клавиатурой список до пяти заметок: по словам из того, что
  набрано между скобками, — в заголовке и тексте, заголовок важнее, свежие выше; пусто — последние.
  Строка: значок вида, заголовок, под ним начало текста бледно.
- Касание строки ставит заголовок между скобками, курсор — за `]]`.
- Кнопка «Связь» в полосе разметки (значок `add_link`) вставляет `[[]]` с курсором внутри — список
  появляется сразу. Под замком (`writeOnly`) список не показывается: строка ничего из базы не
  показывает.
