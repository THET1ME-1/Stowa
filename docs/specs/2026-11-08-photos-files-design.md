# Фото и файлы: что осталось от шага 8

Шаг 8 из `docs/specs/2026-11-03-offline-recall-design.md`, раздел 4. Просьба хозяина 08.11.2026: «Давай, делай 8». Без ИИ и без сети, всё на телефоне.

Уже есть с прошлых шагов: дата, камера и место съёмки из EXIF (факты `takenAt`, `camera`, `takenPlace`), скриншоты отдельно от фото («скрины»), повтор картинки по отпечатку, текст DOCX, XLSX, PPTX, ODT, EPUB, TXT, MD, CSV, JSON, HTML.

## Что делаем

1. **Фото на карте там, где снято.** Есть место съёмки из EXIF — точка заметки на карте там, а не где её сохранили. Как у события: `watchPlaced` берёт `takenPlace`.
2. **Главные цвета.** Новый извлекатель `colors` (версия 1): картинка сжимается системным декодером до 32×32, пиксели раскладываются по двенадцати семьям цвета (красный, оранжевый, жёлтый, зелёный, бирюзовый, голубой, синий, фиолетовый, розовый, коричневый, белый, серый, чёрный), семьи от 12% площади — факты `color` (значение — ключ семьи, число — доля, уточнение — средний цвет HEX), не больше пяти, по убыванию. Источники: вложенные картинки и обложка ссылки или ролика.
   - Поиск: «синее», «красная обложка», «blue», «rot» — фильтр по цвету, подпись «Ищу: синее». Слово цвета понимается на семи языках во всех формах.
   - Доска папки: в порядке «По цвету» — по оттенку главного цвета, серые и чёрно-белые в конце.
3. **Видеофайл.** Новый извлекатель `video` (версия 1) для своих роликов: длина, обложка — кадр на 10% длины в `.stowa/covers/<id>.jpg`, шесть кадров по шкале в `.stowa/frames/<id>/<n>.jpg` (факты `frame`: число — секунда кадра). Достаёт системный `MediaMetadataRetriever` через канал `stowa/media` главного окна и окна «Поделиться». В фоновом движке канала нет — извлекатель там не запускается и ждёт открытия приложения, а не падает.
   - Страница заметки: обложка с длиной на месте пустой рамки и полоса кадров под ней с временем каждого. Касание кадра открывает ролик.
   - Лента и доска: обложка ролика вместо пустой карточки.
4. **Текст PDF.** Свой разбор текстового слоя на Dart (`domain/pdf_text.dart`), без движка: объекты и потоки объектов, сжатие Flate, страницы по дереву, шрифты с `ToUnicode` (кириллица в PDF почти всегда так), простые шрифты WinAnsi, операторы `Tj`, `TJ`, `'`, `"`, перенос строки по сдвигу. Каждая страница — часть текста «стр. N», ищется как остальные документы. Зашифрованный PDF и скан без текста — текста нет, без ошибки. Предел — те же 50 МБ, разбор в своём потоке.
5. **QR-код на фото.** Пакет `zxing2` (чистый Dart, порт ZXing, без нейросети). Извлекатель `qr` (версия 1): картинка до 1000 точек по длинной стороне, поиск QR. Факт `qr`: значение — текст кода, уточнение — вид (ссылка, Wi-Fi, текст).
   - Страница заметки: кнопкой рядом с телефонами и ссылками. Ссылка — «Открыть ссылку из QR», Wi-Fi — «Wi-Fi «имя»» и касание копирует пароль, текст — копируется.
   - Текст кода ищется: «пароль от wifi», адрес сайта с билета.

## Не делаем

Распознавание текста на фото (OCR), лица, сцены — это нейросети, хозяин их отверг. Кадры видео в поиске. Цвет у PDF и документов.

## Решения на мне

Двенадцать семей цвета и порог 12%; шесть кадров по шкале; канал своего кода, а не пакет миниатюр (старые пакеты миниатюр не собираются с `compileSdk 37`); QR включён, раз хозяин велел делать шаг 8 целиком — `zxing2` чистый Dart, к размеру добавит сотни килобайт, а не мегабайт.
