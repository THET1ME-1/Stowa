# Подписка Stowa Sync: покупка, замки, что в неё входит

22.11.2026. Хозяин: «Проверишь, работает ли подписка, и сделай её в приложении под каждую сборку свою. В настройках будет первый пункт — Купить подписку ярким цветом темы… перед покупкой будет вход или регистрация по почте и потом оплата. Но также сделай просто возможность войти без покупки отдельным пунктом в настройках. Для тех, кому мы будем выдавать подписку… Нужен экран стена покупки, где все перечисленные функции покупаются». Следом: «Stowa на сайте и на компьютере бесплатно. Платная только синхронизация»; в подписке — синхронизация со сквозным шифрованием, облако под файлы, публичные ссылки на доски, как в Excalidraw, история версий как в git, боковая панель.

## Что бесплатно и что за подпиской

Бесплатно навсегда: всё на одном устройстве — телефон, сайт stowa.work, программы для компьютера, ИИ по своему ключу.

Stowa Sync — одна подписка, три срока: месяц, 3 месяца, год.

| Что | Сейчас |
|---|---|
| Синхронизация со сквозным шифрованием (`2026-11-17-sync-design.md`) | есть; без подписки сервер отвечает 402 |
| Облако под файлы: вложения, фото, видео, PDF едут той же синхронизацией | есть |
| Боковая панель в браузере (`2026-11-21-browser-panel-design.md`) | **не входит с 23.11.2026, бесплатна** (хозяин: «по сути это расширение, а его любой поставить может»); замка `PanelGate` больше нет |
| История версий как в git: каждая ревизия на сервере, разница строк, возврат | есть с 23.11.2026 (`2026-11-23-version-history-design.md`): месяц — все версии, до года — по дню, удалённое — год |
| Ссылка на доску только для чтения, ключ после `#` | третий этап, тоже «Скоро» |

Экран покупки не продаёт то, чего нет: несделанное помечено «Скоро», пометка снимается с выходом этапа.

## Подписка на аккаунте

Подписка принадлежит аккаунту (почта с кодом). Купил где угодно — работает везде, где вошёл той же почтой. Покупка без входа невозможна: экран покупки сперва просит войти.

**Право на подписку — строка на источник.** У аккаунта может быть несколько прав сразу: выдано вручную, подписка lava, подписка Google Play, подписка App Store. У каждого свой срок и своё состояние (`active`, `cancelled` — доживает оплаченное, `refunded`, `expired`, `pending` — счёт выписан). Срок аккаунта — наибольший срок живых прав; его пересчитывает каждая запись права в той же транзакции. Так возврат или отмена в одном источнике не трогает другой: ручная выдача на год переживает пробную покупку и её возврат.

Одно право принадлежит одному аккаунту: тот же чек Google или Apple с другого аккаунта отклоняется. У аккаунта есть постоянный номер покупателя (UUID); приложение передаёт его магазину при покупке, и если магазин вернул в чеке другой номер — чек чужой.

## Касса по сборке

`--dart-define=STOWA_STORE`: `play` — Google Play, `appstore` — App Store, без значения (APK с GitHub, сайт, компьютер) — внешняя касса. В сборках магазинов внешней кассы нет ни кнопкой, ни ссылкой, ни строкой текста (решение хозяина 17.11): путь к ней отрезан на сборке, это стережёт тест.

- **Google Play:** подписка `stowa_sub`, базовые планы `month`, `quarter`, `year`. Сервер проверяет чек сам, своим ключом сервисного аккаунта с доступом к приложению, подтверждает покупку (без подтверждения за трое суток Google её возвращает), и только после ответа сервера приложение закрывает покупку на телефоне. Тестовые покупки лицензионных тестировщиков принимаются с пометкой «тест»: их делают только люди, которых хозяин сам добавил в Play Console.
- **App Store:** товары `stowa_sub_month`, `stowa_sub_quarter`, `stowa_sub_year`. Сервер спрашивает Apple о покупке по номеру сделки через App Store Server API и ему же верит. Покупки песочницы принимаются с пометкой «тест»: на них проверяет приложение App Review.
- **Внешняя касса (lava):** уровень «Stowa Sync» в подписке кабинета; 299 ₽ / 5 $ / 5 € в месяц, 749 ₽ / 6,99 за 90 дней, 1990 ₽ / 19,99 в год. Оплата идёт только счётом, который заводит сервер на почту аккаунта: покупка с витрины уведомлений не шлёт. Сервер узнаёт свою оплату по номеру своего счёта, продление — по номеру первого счёта (`parentContractId`); уведомление с чужим номером — чужое. Тариф берётся из счёта, а не из уведомления. Повтор уведомления, опрос счёта и уведомление по одному платежу засчитывают его один раз. Потерянное уведомление добирает опрос незакрытых счетов раз в 2 минуты трое суток. Отмена — из приложения; доступ живёт до оплаченного срока.

Магазинные подписки сервер переспрашивает сам, пока срок близок: продление и отмена видны без участия телефона. Отменяют их в самом магазине.

## Экраны

- **Настройки:** первый пункт «Купить подписку», залитый акцентом темы, пока подписки нет; с подпиской на его месте «Stowa Sync до 22 декабря» и экран подписки (тариф, срок, отмена для внешней кассы, «управляется в Google Play / App Store» для магазинных). Отдельный пункт «Войти» — для тех, кому подписку выдали вручную; вошедший видит почту и экран аккаунта: выйти, удалить аккаунт (App Store 5.1.1(v), Google Play; при живой подписке внешней кассы удалить нельзя, пока она не отменена).
- **Экран покупки:** пять пунктов из таблицы, три срока с ценами (в сборках магазинов — цены магазина, иначе — внешней кассы в валюте страны), выгода годовой, «Продолжить». Не вошёл — сперва вход по почте, потом оплата. Внизу условия продления, ссылки на условия и политику, в сборках магазинов «Восстановить покупку».
- **Stowa Sync:** вошёл и подписка есть — работает; вошёл без подписки — вместо управления предложение подписки; не вошёл — «Купить подписку» и «Войти».
- **Боковая панель:** работает у всех, без подписки (23.11.2026). Ссылка `stowa.work/?subscribe` по-прежнему сразу открывает экран подписки.
- **После оплаты внешней кассой** касса возвращает на страницу сайта «Оплата прошла, вернитесь в Stowa», а приложение само узнаёт подписку, вернувшись на передний план: возврат прямо в приложение на сайте упёрся бы в «одна вкладка на хранилище».

Подписку приложение помнит у себя (вошёл, действует, до какого числа, откуда): настройки, Stowa Sync и панель знают её с первого кадра и без сети. Пришла оплата — приложение сразу запускает синхронизацию.

## Проверка

Сервер — тесты на своём Postgres с подставными кассами: счёт, все виды уведомлений lava, повтор, опрос плюс уведомление по одному платежу, отмена, возврат при ручной выдаче, чек Google и Apple, чужой чек, отключённая касса. Приложение — тесты экранов, выбора кассы по сборке и отсутствия внешней кассы в сборках магазинов. Живьём: счёт lava заводится и открывает оплату (не платим), уведомление с телом из документации включает пробный аккаунт. Настоящую покупку в магазинах проверяет хозяин на тестовой сборке.
