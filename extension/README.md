# Stowa в боковой панели браузера

Записать мысль или найти заметку, не уходя со страницы, которую читаешь (STOWA-9). Устройство и проверка — `docs/specs/2026-11-21-browser-panel-design.md`.

## Chrome и Edge

Расширение открывает stowa.work в боковой панели: касание значка Stowa на панели расширений.

Поставить без магазина:

1. `chrome://extensions` (в Edge — `edge://extensions`), включить «Режим разработчика».
2. «Загрузить распакованное расширение» → папка `extension`.
3. Закрепить значок Stowa и нажать его.

## Firefox

`about:debugging` → «Этот Firefox» → «Загрузить временное дополнение» → `extension/manifest.json`. Панель открывается в боковой панели Firefox. Не проверено.

## Vivaldi, Opera, Edge без расширения

Веб-панель с адресом `https://stowa.work/?panel`. Не проверено.

## Как это работает

- Открыта вкладка Stowa — панель базу не открывает: записи и поиск идут через вкладку.
- Вкладки нет — панель и есть Stowa, с теми же заметками.
- Панель держит заметки, а ты открыл обычную вкладку — вкладка забирает их себе сама, панель переходит в лёгкий режим.
- Сайт отдаёт `Cross-Origin-Resource-Policy: cross-origin`: без него изолированная страница расширения фрейм не загрузит.

Значков у расширения нет, пока нет логотипа. Публикация в Chrome Web Store и дополнениях Firefox — по решению владельца.
